# Portfolio site

This is a static, dependency-free portfolio page.

## Preview locally

Open `docs/index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Open Pages.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select branch `main` and folder `/docs`, then Save.
5. Wait for the Pages deployment to finish; GitHub will show the published URL in the Pages settings.

The page links to the repository's public code and an inquiry issue template. It contains no customer testimonials and labels the sample report as fictional.
