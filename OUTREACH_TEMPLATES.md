# Client Outreach Templates

Personalize each message. Do not mass-spam, claim experience you cannot prove, or promise to find every bug.

## Short message

Hi! I provide small, clearly scoped software QA checks for websites, Android apps, and read-only APIs. I can test an agreed set of flows, document reproducible issues with screenshots, and provide a concise report. My introductory tasks start around $15. If you have a staging build or test URL and authorization to test it, I can suggest a fixed scope and price.

## API-focused message

Hi! I can run a small read-only API smoke/contract check against endpoints you own or authorize. I check HTTP status, JSON validity, required fields, and agreed expected values, then provide a JSON/HTML report with findings. I do not perform load testing or intrusive security testing. If you share the API documentation and test base URL (without secrets), I can propose a small fixed-price test.

## Android-focused message

Hi! I offer manual Android app QA on an agreed device/Android version. I check installation/startup, navigation, key buttons and flows, layout issues, and reproducible crashes. You receive a concise report with steps and screenshots where possible. Please share a test build and the flows you want checked; no production credentials or real customer data are needed.
